# Planned first Biscuit visual direction

**Netflix-inspired cinematic home UI** — planned after Phase 3 on a separate branch.
No visual implementation or assets are introduced by this document.

- Dark, AMOLED-friendly base.
- Large cinematic hero artwork.
- Horizontal media rows: Continue Watching, Recently Added, Movies, TV / Anime.
- Large posters and backdrops.
- Smooth scrolling and transitions.
- Clean, minimal bottom/top navigation.
- Biscuit's own branding, typography and icons.

Use the general cinematic streaming-app interaction style while making Biscuit visually distinct.
Do not copy Netflix logos, proprietary artwork, exact layouts, sounds, animations or branded assets.
